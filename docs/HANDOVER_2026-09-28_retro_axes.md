## 1. Why this is worth doing

Two axes were added on 2026-09-28 and each immediately overturned a published conclusion:

* **structure coherence** — the local agreement of the luminance gradient. Every earlier statistic
  in this project measures *how far the image moved*; none could tell moving toward something from
  falling apart. The five conditions the project recommended on 2026-09-27 turned out to be the
  five worst of eighty on this axis.
* **energy at each scale** — a Gaussian pyramid, 1–2 px through 16–32 px. Every earlier texture
  statistic sums over scale before reporting, and so cannot distinguish "grain added at 4–8 px"
  from "detail stripped monotonically" from "a notch at 2–8 px". Those are three different damages
  and an observer named them before any measurement did.

Every published reading of every bench was made without either. The absolute values now exist for
all of them; what is missing is the join to each bench's baseline, because each bench names its
baselines differently.

## 3. What to produce, per bench

One script `experiments/retro_<bench>_reading.py` and one result document, each following
`retro_atlas_reading.py`:

1. **Parse the filename into (prompt family, condition, seed)** with an explicit regular
   expression, and **print how many files failed to parse**. A silent parse failure is a silently
   dropped condition.
2. **Ratios against the matching baseline** — same prompt family, same seed, never a pooled one:
   `coherence_ratio`, `band0_ratio` … `band4_ratio`, `peak_band`, `contrast_ratio`, `chroma_ratio`.
3. **Two readings, the same two as the atlas:**
   * does the coherence ratio *discriminate* on this bench — what is its spread, and what fraction
     of cells fall below 0.90? A bench where nothing moves is telling you the axis is blind there,
     which is a result, not a failure.
   * which conditions move the image a lot **and lose the line**, and which move it a lot **and
     keep it** (coherence ≥ 0.98).
4. **Then the question that pays for the work:** take the claims that bench's published document
   makes and ask whether any of them was made on a condition that the coherence axis now says is a
   collapse. Name them. Do not change any claim's status — list them and stop.

## 4. Traps, all of them paid for already

* **Do not divide the two axes by one another** to make a single score. A displacement-over-damage
  ratio puts a quantity that can approach zero in the denominator; this project got that wrong
  three times in one day. Rank by Pareto dominance, or report both columns.
* **Do not treat `band*_ratio` as one number.** The shape of the profile is the finding: monotone
  stripping and a mid-scale notch are different damages with the same total.
* **The unit is the condition, not the render** (pitfall 17). Pool seeds before any test.
* **Coherence is near-blind on flat styles.** On the atlas it discriminates on photo, watercolour
  and charcoal and barely moves on lowpoly, claymation, ukiyo-e and pixel, whose baseline coherence
  sits near a floor. If a bench's style is flat, say the axis cannot see it rather than reporting a
  clean null.
* **Check the parse against the folder count.** `624 + 24 baselines + 1 determinism check = 649` is
  the atlas's arithmetic; write the equivalent line for each bench and make it balance.
