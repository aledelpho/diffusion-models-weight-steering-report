| **48** | Porting a prompt corpus from the model that understands it best to the one that understands it least | The cross-architecture protocol reused the 10 stage-7 confirmation prompts verbatim on Anima, on the reasoning that changing a single character would break continuity with every Krea-2 result and introduce a prompt confound into the comparison | Verbatim is only neutral when both models parse the text equally well. Anima is trained toward keyword-structured prompts and degrades on long clauses whose word relations have to be resolved, so the shared corpus is not shared: its baseline renders start from a worse comprehension of the same string, and any edit is then measured on a degraded baseline. Comprehension becomes a silent covariate that differs by architecture — exactly the variable the matched design was built to hold still | Let the model with the **narrowest input tolerance** set the prompt protocol, and port upward: build and validate the corpus on the constrained model, then carry it to the more capable one, which can absorb a simpler format without loss. Size is not the criterion, format rigidity is. And parity is measured, not assumed: score prompt adherence on the named attributes of the baseline renders of both models before comparing anything else. Note the cost of the fix so it is not traded blindly — a corpus shaped to the constrained model's native format sits in a more canonical region of *its* prior, which may amplify or suppress the edit for reasons of its own |
| **49** | Naming a scaling law from a single dose sweep at a single step count | Three doses (100%, 50%, 30%) were rendered at 30 sampling steps; 30% was the one that converged without artefacts. Since the reference regime was 9 steps and $9/30 = 0.30$, the result was written up as a discovered law, $\text{dose} \propto D \times N_{\text{steps}}/N_{\text{ref}}$ | Two numbers agreeing at one point is a coincidence with a plausible story attached, not a measured relation. The sweep has one step count, so the exponent on $N_{\text{steps}}$ is unconstrained: $1/N$, $1/\sqrt{N}$ and a step-independent threshold near 0.3 all fit the single observation equally well. The write-up then compounded it — the bridge arm was rendered at 30% while running at 9 steps, which under the proposed law should have been 100%, so the arm was under-dosed 3.3× by the document's own rule and its failure to converge was attributed to the sampling regime instead | A dose-response relation needs the threshold located at **two or more step counts** and the fitted exponent reported with its uncertainty. Until then call it a calibration constant for one regime, which is useful and honest, and check that every arm of the experiment is dosed according to whatever rule is being claimed |

The sentence is arithmetically true and causally backwards, and it hands the treatment an effect that belongs to the control. The same file shows the mirror-image error waiting to happen: `lbp_entropy` rises in **all four** conditions, at the permutation floor in each, so it separates nothing and would support any story told about any of them | Every treatment-versus-control contrast is reported alongside both arms' contrast against the **baseline**, in the same table. A feature where only the control moves is a finding about the control; a feature where everything moves is not a finding at all |
